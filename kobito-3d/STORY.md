# 小人一家と汚れた世界 — 物語バイブル

作中の絵本タイトル（＝この物語そのもの）：**『みどりのはじまり』**

---

## 0. 一行の芯（ここに全部を向ける）

> **諦めた心が世界を汚し、諦めなかった心が世界を緑に還す。**

最後に残したい感情：**「もう無理だと思っていた場所が、ちゃんと“家”になった」**。
出だしで「おじいの緑話」をみんなが呆れて聞く——この“見下し”を丁寧に置くほど、
ラストで「本当だった」と分かる瞬間の涙が大きくなる。冒頭の呆れは、最後の感動のための投資。

---

## 1. 世界観

- 小人にとっての世界は「人間の世界のミニチュア」。地面＝砂利やタイルの目地、崖＝縁石、
  大木＝雑草、川＝排水の流れ、ダンジョン＝排水溝の中。ゴミ（吸い殻・空き缶・葉）は巨大な地形。
- 世界は**ヘドロ**に侵されつつある。ヘドロは「諦め」が形になったもの。放っておくと広がる。
- **敵は倒さない、癒やす。** 虫はヘドロに侵されて苦しくて暴れているだけ。
  攻撃＝汚れを叩き落として正気に戻す行為。癒やされた生き物は去るか、**仲間になって力を授ける**。
- 雨はこの規模では**大災害**（洪水）。天候が物語の山場に使える。

---

## 2. 登場人物

### 家族
- **父・母** … プレイヤー2人（オンライン協力）。諦めない大人の代表。
- **おじい** … 緑の世界を覚えている最後の世代。**最後の種**をこっそり握っている。
  冒頭、緑を語るが周りは「またボケが始まった」と呆れる。末っ子だけが信じる。
  → 終章、最初の一輪が咲くのを**見届けて安らかに逝く**。

### 8人の子ども（主役級・一人ひとりにドラマ）
1. **スミレ（長女）** … 責任感の塊。親代わりに弟妹をまとめる。弱音を吐けない。
   ドラマ：**一人で背負わなくていい**と気づく。
2. **カヤ（長男）** … 不満分子。「なんでこんな汚い所を掃除しなきゃ」。
   **ラスボスの絶望のミニチュア**。不満→情熱に転じ、最後は誰より熱く“家”を守る。
   彼の口から出る「この汚れた場所を、俺は“家”って呼びたい」が、ラスボス浄化の決め手。
3–4. **リン＆ラン（双子）** … 「二人でひとつ」と括られる不満。
   片方が先に飛ぶ力を授かり、初めて“別々”に。離れて相手の大切さを知り、
   最後は**自分たちの意思で「一緒に飛ぶ」を選ぶ**（＝夫婦協力の子ども版）。
5. **つぼみ（末っ子）** … 緑を知らない世代。**おじいの話を唯一まっすぐ信じる子**。
   終章、**最初に花に触れる**。そこから家族全員が輪になって見る。
6. **無鉄砲な子** … 誰より先に飛びたがる。飛行一番乗りで痛い目→仲間の力を借りる大切さ。
7. **内気な子** … 声が小さい。癒やした生き物と最初に心を通わせるのはこの子（弱さが強みに）。
8. **食いしん坊（緩衝材）** … コメディ担当。重い話ほど、緊張を緩める子が要る。

### その他
- **集落の長** … かつてヘドロで家族を失い、「死んだ世界に希望を抱くな」を掟にして隠れ潜む。
  → 最後は**救われて、一緒に緑を見る**。ラスボス（諦めきった者）との対比になる。
- **ヘドロの主（ラスボス）** … 昔このやり方を諦め、絶望してヘドロに溶けた小人。
  倒すのではなく**夫婦＋飛べる子どもたち＋これまで癒やした全生物で“癒やす”**。
- **人間の子** … 終盤、育った庭を見つけ、踏み潰さず**そっと守る**。
  → 30年後、**孫8人にこの物語を語る祖父母**になる（＝額縁の語り部）。

## 3. 章立て（序 ＋ 本編6 ＋ 終 ＋ 額縁）

各章、**常に敵が出る＋章が進むごとに増強**（雑魚＋中ボス）。

### 序章｜おじいの、みどりの話
絵本の表紙が開く。おじいが「昔はな、地面が緑で、花が咲いて…」。子も周りの小人も呆れる。
末っ子つぼみだけが目を輝かせる。おじいは最後の種を握っている（伏線）。
- 敵：戸惑うアリ1匹（チュートリアル）。授かる力：なし。

### 第1章｜たどり着いた隙間
もっとひどい場所から逃げてきた家族。排水溝の一角を“家”に決める。最初の浄化。
夫婦協力と8人の関係性を提示。スミレの責任感、カヤの不満が早速こぼれる。
- 敵：**アリ**。 授かる力：**力（押す・運ぶが強くなる）**＝ゴミ掃除が楽に。

### 第2章｜他にも、いた
別の隠れ家で、散らばって生きる小人と出会う。「**集落があるらしい**」。
“自分たちだけじゃない”希望。カヤ「そっちの方が楽なんじゃ」と揺れ始める。
- 敵：アリ＋働きアリの群れ。 中ボス：**女王アリ**。
  癒やすとアリの巣が仲間に（土を耕す）。 授かる力：**掘る（地面に潜って近道）**。

### 第3章｜集落の一波乱
集落へ。だが集落は**とっくに諦めて隠れ潜むだけ**——「死んだ世界に労力を割くな」が掟。
長は昔ヘドロで家族を失い、希望を禁じている。**カヤは残りたがる。双子の片割れがはぐれる**（双子ドラマ始動）。
家族の“癒やして還す”生き方が真っ向から否定される。去るとき、数人の若い小人が付いてくる。
- 敵：ダンゴムシ、ハサミムシ。 中ボス：**ムカデ**（集落を脅かす長い脅威）。
  授かる力：**転がり体当たり／壁登り**。

### 第4章｜上流へ、そして最悪の日
世界が広がり、汚染源が増える。**雨→洪水で、築いた庭が流される**。どん底。
**おじいが弱っていく。** 「諦め」が家族に忍び寄り、カヤの不満が頂点に。
- 敵：ボウフラ、アメンボ、カ。 中ボス：**ゲンゴロウ（水中ボス）**。
  授かる力：**水を渡る（水面を滑る・少し潜る）**。

### 第5章｜授かる力（全体の約2/3・飛行解禁）
どん底からの反転。**癒やした空の生き物が一つずつ“飛ぶ力”を授け、それが合わさって飛行になる。**
子どもたちが各々、生き物と絆を結ぶ。無鉄砲な子がバッタと組んで最初に飛び、痛い目→仲間の力で本当に飛ぶ。
**双子の山場：片割れがトンボと組んで先に飛び、離れる怖さを越えて“一緒に飛ぶ”を選ぶ。**
- 敵：バッタ・テントウムシ・チョウ・トンボ・ハチ。 中ボス：**オオスズメバチ（空の脅威）**。
  授かる力：各パーツ → 合わさって**自由飛行**（下の対応表）。

### 第6章｜源にいたのは
汚染の源へ。そこにいるのは**昔このやり方を諦めた小人＝ヘドロの主**。
倒すのではなく、**夫婦＋飛べる子どもたち＋これまで癒やした全生物＋信じてくれた集落の者**で“癒やす”のが最終決戦。総決算。
カヤの「この汚れた場所を、俺は“家”って呼びたい」が決め手になる。
- 敵：ヘドロに侵された虫たち（総登場）。 ラスボス：**ヘドロの主（癒やす）**。

### 終章｜みどり
世界が芽吹く。**末っ子つぼみが、生まれて初めて本物の花に触れる。** そこから**家族全員が輪になって見る**。
**おじいが、最初の一輪が咲くのを見届けて、安らかに逝く。**「な？　言ったろう」。
集落の長も救われ、一緒に緑を見る。序章の“呆れ”が、ここで涙に変わる。
このとき**人間の子が庭を見つけ、そっと守る**（スケールの出会い）。

### 額縁の閉じ｜30年後
**30年後。** あの人間の子は祖父母になり、**孫8人**に絵本『みどりのはじまり』の
“緑のはじまり”の場面だけを、要約して語り聞かせている（＝小人の8兄弟と鏡）。
語り終え、**絵本を閉じる**——この物語は、語り継がれる一冊の絵本だった。
窓辺の小さな庭で、**小人がその様子をそっと見ている**。人間と小人の距離は、あの頃よりずっと近い。
永遠に語り継がれる物語となった。（完）

## 4. 敵 ×「授かる力」対応表（癒やす → 力 → 飛行）

| 章 | 主な敵（癒やす対象） | 中ボス | 授かる力 |
|---|---|---|---|
| 序 | 戸惑うアリ（チュートリアル） | — | — |
| 1 | アリ | — | 力（押す・運ぶ強化） |
| 2 | アリ＋働きアリ | 女王アリ | 掘る（地面に潜る近道） |
| 3 | ダンゴムシ・ハサミムシ | ムカデ | 転がり体当たり／壁登り |
| 4 | ボウフラ・アメンボ・カ | ゲンゴロウ | 水を渡る（水面滑走・潜水） |
| 5 | バッタ・テントウ・チョウ・トンボ・ハチ | オオスズメバチ | **飛行**（下記5パーツが合体） |
| 6 | ヘドロに侵された虫（総登場） | **ヘドロの主＝諦めた小人** | 癒やしの共鳴（全員協力） |
| 終 | 戦闘なし | — | — |

### 第5章：飛行を組み上げる5パーツ（子どもの絆と対応）
- **バッタ** … 高く跳ぶ（無鉄砲な子）
- **テントウムシ** … ふわっと浮く（内気な子）
- **チョウ** … 滑空
- **トンボ** … 空中静止（ホバリング）（双子の片割れ）
- **ハチ** … 上昇

5匹すべてを癒やすと合わさって**自由飛行**が解禁。

## 5. ゲーム実装への接続（M0〜M7）

| マイルストーン | 物語の対応 | 実装メモ |
|---|---|---|
| M0 土台 | （済） | 完了 |
| M1 歩ける | 序章〜第1章 | 完了 |
| M2 戦える | 第1章（アリ／癒やす） | 「倒す」を**「癒やす」**に意味づけ変更。虫は癒やすと退場or仲間 |
| M3 育つ・掃除 | 第1〜2章 | 環境回復度＝ヘドロ後退の可視化。女王アリ（中ボス） |
| M4 夫婦Co-op・子NPC | 第2〜3章 | 8人の追従隊列＝子どもたち。集落の一波乱 |
| M5 世界拡張・飛行 | 第4〜5章 | **飛行の解禁をLv3から「第5章＝癒やした力の集約」へ変更**。洪水の setpiece |
| M6 縦切り完成 | 第6章〜終章 | ラスボス（癒やす）／エンディングAＣ／額縁 |
| M7 その後 | 追加章・オンライン拡張 | 集落メンバーを増やす等 |

### いま入っている仕組みとの整合
- **環境回復度（WorldState）** … 「ヘドロの後退」そのもの。上がるほど地面が茶→緑、空が晴れる。
  → 演出強化の余地：花が生える、癒やした虫が画面を舞う、BGMに緑が差す。
- **敵（bug）** … 「癒やす」に読み替え。撃破エフェクトを“汚れが落ちて色が澄む”に。
  癒やした種類ごとに**授かる力フラグ**を持たせ、飛行は5フラグ達成で解禁（現在のLv3判定を置換）。
- **データ駆動（data/*.tres）** … 敵の増強（章ごと）＝tresを増やすだけ。中ボスもtresで管理。
