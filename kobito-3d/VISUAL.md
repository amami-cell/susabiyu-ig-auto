# 見た目とワールドの世界観（アート指針）

## 0. 芯：見た目そのものがゲームの主題
「掃除するほど世界が緑に還る」——この変化が**一番の見せ場**。
だから見た目は飾りではなく、**環境回復度(WorldState.recovery)に連動して変わる**のが大原則。
実装済み：空・霧・草・花・地面の色が、回復度で 褐色の澱み → 緑の楽園 へ移り変わる。

## 1. 小人視点＝人間世界のミニチュア
地形を作り込まない。現実の小物を「巨大なオブジェクト」として置くだけで世界になる。
- 地面＝砂利・タイルの目地／崖＝縁石／大木＝雑草／川＝排水の流れ／ダンジョン＝排水溝。
- **霧を効かせて“ジオラマ感”**を出す（被写界深度の代わり）。回復すると霧が晴れる二重の意味。

## 2. 「緑に還る」フィードバック（実装済み・第一段階）
すべて手続き生成＝外部素材ゼロ・スマホ安全（草500・花60も MultiMesh で各1ドローコール）。
- **空**：灰色 → 青空（ProceduralSky、回復度で補間）。
- **霧**：澱んだ濃霧（近くしか見えない）→ 澄んだ空気。
- **草**：回復度で“伸びる”（高さ0 → 満ちる）。汚れているうちは生えていない。
- **花**：回復30%あたりから咲き始め、100%で満開（桃・黄・白・紫）。
- **地面**：茶 → 緑。
今後：シェーダーで地面に苔・水たまりの照り、癒やした虫が舞う、風で草が揺れる。

## 3. キャラの見た目（当面は箱＋無料アセット）
- 段階A（今）：カプセル＋球のプレースホルダー。色で描き分け（CHARACTERS.md 準拠）。
  面白さが固まるまで箱のまま進める。見た目の作り込みは“面白さが確定してからのご褒美”。
- 段階B：Blender でローポリの小人（顔は点2つでいい）。**あえて低ポリ・単純形状が正義**。
- 段階C：Mixamo で歩き/走り/癒やしモーション。8人は1体を色替えでインスタンス化。

## 4. エリアごとの色設計（AREAS.md と対応）
汚染時 → 浄化後 の2枚を各エリアで用意する（回復度で補間）。
| エリア | 汚染時の基調 | 浄化後の基調 |
|---|---|---|
| 庭(ハブ) | 褐色・灰の霧 | 新緑・青空・花 |
| ①荒廃した街 | 錆・煤けたグレー | 蔦の緑がビルを覆う |
| ②遺跡 | 苔むした灰緑・薄暗い | 陽の差す聖域・花 |
| ③雪山 | 白と灰・寒色 | 雪解けの若草色 |
| ④マグマ | 黒赤・陽炎 | 木陰のある温かな丘 |
| ⑤中心=源 | ヘドロの黒紫 | 世界樹の大輪 |

## 6. スマホ最適化の約束（無料枠・スマホ本命）
- 描画は gl_compatibility（古い端末でも動く）。影は控えめ、ポリゴンは低く。
- 群れは MultiMesh（草・花・将来の落ち葉）。ドローコールを増やさない。
- 重い後処理（SSAO/DOF等）は使わず、霧と色で“それっぽさ”を出す。
