# 複数店舗（23店舗展開）プラン — 携帯ホーム風の店舗アイコン画面

> ステータス: **仕様確定・実装は2店舗目が決まってから**（2026-06-28 合意）
> 現在は すさび湯三条 の1店舗のみ運用中。

## やりたいこと（ユーザー要望）
- 携帯のホーム画面のように、**店舗ロゴのアイコン**を並べた「店舗選択ホーム」。
- 店舗が増えたら**横（右）スクロール**でアイコンが並ぶ。
- アイコン下に**識別名**を表示（屋号がかぶるため）。例: すさび湯 → 下に「河原町三条／歌舞伎町／三宮」。
- アイコンを**長押し → −（マイナス）で非表示**にできる。
- 別画面で**再表示する店舗を複数選択**できる。
- 担当外（通知不要）の店舗は隠せる。

## 通知の絞り込み（確定）
- **「表示中の店舗」だけに通知**が届く。非表示にした店舗の通知は来ない。
- 端末ごとに、表示中＝担当する店舗の購読だけを有効化する。

## データ構成（¥0のまま実現）
- **店舗一覧シート**（新タブ `店舗` など）: 列の例
  `storeId | 屋号(full) | shortName(識別名) | logoUrl | gasUrl | sheetId | enabled`
- 各店の**ロゴ**は Drive かリポジトリ public に置き、jsDelivr 等で配信。
- 各店の**購読リスト**は店舗ごとに分ける（既存の `購読` タブを storeId 付きにするか、店舗シートごとに持つ）。

## PWA 画面遷移
1. 起動 → **店舗選択ホーム**（ロゴ＋識別名のグリッド、横スクロール）。
2. 店舗タップ → その店舗の **確認 / 見本**（現行画面）。屋号はヘッダーに表示済み。
3. アイコン**長押し → −**で非表示（localStorage に hidden 店舗を保存）。
4. 「店舗を表示/非表示」設定画面で**複数選択して再表示**。
5. 表示中の店舗に対してのみ Web Push を購読（通知の絞り込み）。

## 実装メモ
- 屋号は既に `STORE_NAME`（config.js）でヘッダー表示済み。多店舗時は店舗ごとに切替。
- GAS は店舗ごとに分けるか、1つのGASで storeId を受けて分岐するかは2店舗目決定時に判断。
- 既存の単店運用（すさび湯三条）はそのまま1つ目のアイコンとして組み込める。
